    About this build

    Early access
    Local-first by design

    The interface can work offline after installation. Running Windows applications requires a compatible emulator runtime, guest operating system, and input integration that are not included yet.

    EXE Deck is an experimental browser-local PWA. Importing a Windows EXE stores the file; it does not execute it. DirectX games are not currently supported.
